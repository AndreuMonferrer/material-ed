Los datos que el programa recibe:

  • Texto escrito por el usuario
  • Un archivo leído del disco
  • Datos recibidos de otro sistema
  • Una señal de un sensor
  • Una petición enviada desde el navegador

La entrada puede venir del usuario, de otro programa o de un dispositivo físico.

Lo que el programa hace con los datos:

  • Calcular un resultado a partir de los datos
  • Comprobar si se cumple una condición
  • Transformar o filtrar la información
  • Repetir una acción varias veces
  • Guardar o modificar información

El proceso es la parte que decide qué hacer con la entrada antes de generar una salida.

El resultado que el programa produce:

  • Un número o mensaje en pantalla
  • Un archivo guardado en disco
  • Una petición enviada a otro sistema
  • Encender un LED o mover un motor
  • Una página web devuelta al navegador

La salida puede ser para el usuario, para otro programa o para un dispositivo físico.
